Simulasi konsep UI cobserve mission control: satu layar, panel grafik, tile per node, drill-down lewat overlay

ukuran 

 
Klik layar lalu pakai keyboard: 1–8 fokus panel (8 = sessions) · tab panel berikutnya · ⏎ buka panel itu satu layar · esc kembali · ←→↑↓ pilih di dalam panel · e explain this number · : palette · ? kunci · \ (atau ctrl+\) Claude mengambang · p preset tata letak · [ ] replay per menit, t live · x lalu y cancel job (di panel queue) · y copy link · n catatan · z snooze · s sort · + densitas. Mouse: klik judul panel, tile, baris. Grafik memakai blok; di terminal asli defaultnya braille. Semua angka dari fleet buatan, rumus §5 yang sama.
